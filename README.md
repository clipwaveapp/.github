# ClipWave

Free `!clip` bot for **YouTube**, **Twitch**, and **Kick** live streams.
Viewers type `!clip` in chat (Nightbot-powered) — streamers get timestamped
public clip pages, Discord alerts, and OBS overlays.

🌐 Website: https://clipwave.site · 📖 Setup guides: https://clipwave.site/guides

## Repositories

| Repo | What it is |
|---|---|
| [clipwave-react](https://github.com/clipwaveapp/clipwave-react) | Web platform — channel pages, clips feed, dashboards |
| [clipwave-app](https://github.com/clipwaveapp/clipwave-app) | Desktop app (Electron) — browse and download clips locally |
| [clipwave-vps-api](https://github.com/clipwaveapp/clipwave-vps-api) | Backend API (Flask) — chat commands, timestamps, monitor |

## For streamers

1. Sign in at [clipwave.site](https://clipwave.site) with your channel.
2. Add the Nightbot `!clip` command from your dashboard ([guide](https://clipwave.site/guides/youtube-clip-command-nightbot)).
3. Go live — chat clips, pages and Discord alerts happen automatically.
